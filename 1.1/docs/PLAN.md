# 拼豆图纸工具 · 黑客松方案

> 一句话：**把任何一张图变成能直接照着摆的拼豆图纸，而且能在平板上改。**

状态：草案（据 11-06 23:20–11-07 00:45 与队友的聊天整理）
队友：汉堡包（GitHub `sshanersshaner`）

---

## 1. 问题与用户

**用户**：拼豆（Perler beads）玩家，尤其新手。

**真实痛点**（队友原话）：
- 图纸难找，网上现成的图**太小**，放大了就糊
- 找到图也没有**色号标注**，不知道每格用哪个色
- 想改图（换色、加内容、翻转）只能重新找，没有工具
- 不知道自己手上的豆够不够，摆到一半才发现缺色

**为什么值得做**：拼豆是手工圈里持续增长的品类，现成工具都是海外简易生成器，缺"可编辑 + 色号 + 库存"这一层。

## 2. 产品形态

## 4. 已知 Bug（队友记录）

1. 上传 A 图 → 编辑成 B 图 → 点 ×4 放大，**基于 A 而不是 B** 重新生成，编辑丢失
2. 画图工具**没有调色板**，只能吸色
3. 颜色识别**过于敏感**，复杂图片会出大量噪点色块，需要降噪/合并相近色

## 7. 路演脚本（5 分钟）

1. **30s 痛点**：现场举一张淘宝买的拼豆图纸——"图太小，没有色号，想改一点得重买"
2. **90s 演示**：现场拍一张照片 → 30 秒出图纸 → 放大看色号 → 点两格换色 → 库存自动变化
3. **60s 用户验证**：播放/展示现场同学试用片段，讲他们提出的一个问题和我们怎么改的
4. **60s 价值**：谁付费（玩家买图纸/色板包）、成本（纯前端，可离线）
5. **30s 收尾**：下一步（社区图纸库、电商色板对接）
