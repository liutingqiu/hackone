# 卡点清单（friction）· 2026-11-07

> 排序依据：**会让用户放弃的程度** —— 从上往下，第 1 条足以让新手直接关掉页面，越往下越"忍着能用"。
> 每条都给复现路径：从哪一步开始、点了什么、看到什么。证据在 `docs/evidence/user-testing/`。

**先说结论**：1–3 条是"产品价值断了"，4–8 条是"以为它坏了"，9–14 条是"老手会觉得糙"。

---

## 1. 「导出 PNG」导出的图不能照着摆（没有色号 / 行列号 / 用量清单）

- 复现：打开首页 → 上传任意照片 → 右上「导出 PNG」→ 打开下载的 `pattern.png`（896×896）。
- 看到：只有色块、网格线、4 条红色分板线、角落的板号 1/2/3/4。**每格没有色号，边上没有行列号，整张图没有一处写"共几颗、几个色、每个色多少颗"**。
- 为什么致命：用户来这里的目的是"照着摆"，这张图只能"看"。新手拿到的第一份成品就是废的，而且他不会知道右边还有个能用的按钮。
- 证据：`a-06-exported-png.png`、`a-08-print-plain-png.png`（打印这张图：一页 A4，图案缩在上半页，透明区域在深色/冲印下变黑）。
- 严重度：**会让新手直接放弃**。老手会转回 Excel。

## 2. 画布默认就被裁掉三分之一，放大后只能看到 11 列

- 复现：桌面 1280×992 → 上传照片 → 默认「每行格数 48 / 格子大小 14px」→ 画布 672px 宽，可视区只有 445px，**右边 1/3 看不到**，只能拖底部的细滚动条；把「格子大小」拖到 40px，画布 1920px，可视区还是 445px，**一屏只剩约 11 列**。
- 看到：找不到"整张图"和"我要看的那一块"之间的位置关系；缩放后视图跳回左上角，失去上下文；没有"适应窗口 / 100% / 定位到某板"。
- 证据：`a-02-photo-result.png`（右侧被切断）、`a-03-zoom40.png`（放大后只剩左上角）。
- 严重度：**会让新手放弃**（"我根本看不全我做的图"）；老手忍着用。

## 3. 格子里的色号被切掉首字母（A07 → 「07」），默认缩放下干脆不显示

- 复现：上传照片 → 勾着「显示色号」→ 14px 下**一个字都不显示**；把「格子大小」拖到 40px → 格子里出现「04」「03」「07」。上传 32×32 像素图后同样：A01→「01」、A07→「07」、F03→「03」。
- 看到：C04 与 J04、A07 与 B07 在屏幕上完全同形；按这个图摆必然错色。新版（MARD 291）更严重：G14→「14」、H1→「1」、C5→「5」、M15→「15」，只剩后一两位。
- 证据：`a-03b-code-clipped.png`、`b-05-code-clipped.png`、`latest-code-clipped.png`（新版实测）。
- 严重度：**会让老手放弃**（他比新手更依赖色号）；新手看不懂"04"。

## 4. 「导出 PNG」点下去 5.2 秒零反馈

- 复现：任意图 → 点右上「导出 PNG」→ 页面没有任何变化（没有"正在生成"、没有转圈、按钮不变灰、没有完成提示），5.21s / 5.22s 后浏览器下载栏才出现 pattern.png。
- 看到：像没点上；用户会连点 2–3 次，得到 `pattern.png`、`pattern (1).png`、`pattern (2).png`。
- 证据：两次点击到下载完成计时 5215ms / 5209ms；`a-05-after-export-click.png`（点完后的界面与点之前一模一样）。
- 严重度：**会让用户以为坏了**。

## 5. 传错文件完全没有任何提示（四种错法，四种静默）

- 复现与看到：
  - 传一个把 .txt 改成 .png 的文件 → **页面毫无反应**，仍是上一张图，无报错（`a-10-fake-file.png`）；
  - 传全透明 PNG → 安静地出「2304 颗、1 色」全白图；
  - 传纯白 500×500 → 同上，1 色；
  - 传 1×1 像素图 → 安静地拉伸成 48×48、1 色。
- 严重度：**会让用户以为网站坏了**。一句"这张图读不出来"就能救回来，现在一句都没有。

## 6. 像素图默认被缩放插值，原图 3 色变成 8 色（老手核心场景）

- 复现：传 32×32、本来只有 3 色的像素图 → 默认「每行格数 48」→ 结果 8 色 / 2304 颗，多出「F02 珊瑚红 4 颗」「B04 玫红 124 颗」这类原图不存在的过渡色；把「每行格数」手动拖到 32 才恢复 3 色 / 1024 颗。
- 看到：页面没有"原图 32×32，建议 32 格 / 1:1 导入"的任何提示，全靠老手自己算。
- 证据：`b-02-pixel48.png`、`b-03-pixel32.png`。
- 严重度：老手会在这一步骂人，但能自己救（新手救不了，新手根本不知道有这回事）。

## 7. 「导出分板拼装图」= 新标签页 + 自动弹出的打印对话框，没有一句页内说明

- 复现：上传图 → 点右侧「导出分板拼装图」→ **新开一个 about:blank 标签页，450ms 后浏览器打印对话框自动弹出**；关掉对话框后这张"图纸页"就留在标签里，没有下载按钮、没有"保存 PDF"的说明（页面里其实有一个红色「打印 / 保存 PDF」浮动按钮，但在打印预览挡住时看不到）。
- 看到：新手不知道刚才发生了什么，也不知道要选"另存为 PDF"；如果浏览器拦截弹窗，页面上**没有任何提示**，等于点了没反应。
- 证据：`a-09-split-overview.png`、`a-09b-split-board1.png`、`split-print-a4-5pages.pdf`（5 页 A4，内容本身很好）。
- 严重度：功能是王牌，入口和预期对不上，会劝退一半新手。

## 8. 刷新即丢图，没有保存、没有提醒

- 复现：上传 → 调参数 → 刷新（Ctrl+R）→ 图纸回到「—」，颜色列表清空，参数回到 48/14。
- 看到：没有任何"未保存/将丢失"的提示；浏览器后退也一样。
- 证据：`b-09-after-reload.png`。
- 严重度：辛苦调好的图丢了会直接放弃；但只影响"中途刷新"的人。

## 9. 术语没有解释，小白模式里仍然露出「分板」

- 复现：首屏（旧版默认、新版小白模式）→ 右侧直接写「分板 2 × 2 = 4 块（29×29）」「导出分板拼装图」；左侧旧版有「杂色合并阈值 2 颗」。
- 看到：新手不知道拼豆底板是 29×29，所以「4 块（29×29）」是天书；「每行格数」不知道是豆还是像素；「杂色合并阈值」没有任何说明。
- 严重度：不会当场放弃，但会一直"猜"。

## 10. 手机端：拖拽提示不成立、hover 提示失效、按钮换行、画布被裁

- 复现：390×844 打开 → 空画布写着「**拖**一张图进来」（手机没法拖）；出图后底部写「**鼠标**移到图纸上看色号」（手机没有鼠标，色号完全查不到）；顶部「上传图片」「导出 PNG」被挤成两行；画布 672px 塞进 390px，只能看到左边一半。
- 证据：`m-01-mobile-empty.png`、`m-02-mobile-result.png`。
- 严重度：手机是这类用户的主场景，忍着能用但体验打折。

## 11. 不能改单格（没有画笔 / 橡皮 / 撤销）

- 复现：出图后找遍页面：只有三个滑杆、两个勾选、一个下拉、三个按钮；改一个杂色只能重新做一张图再传。
- 严重度：老手会因此回到 Excel（"能改"是 Excel 的核心价值）。

## 12. 用量清单不能复制、不能导 CSV

- 复现：右侧色号列表（C04 棕肤 832 …）是纯展示，鼠标拖选无反应，没有「复制」「导出 CSV」。
- 严重度：老手要拿这个表去买豆/对库存，只能手抄 14–36 行。

## 13. 导出的文件名永远叫 pattern.png

- 复现：连续导出两次 → `pattern.png`、`pattern (1).png`；不含日期、不含图名、不含格数。
- 严重度：轻微，但对做定制单的人是长期噪音。

## 14. 页面上没有任何"当前用哪套色板 / 共几色"的说明

- 复现：同一张照片，旧版出 14 色、新版出 36 色（色号出现 ZG6 / M9 / H5 这类编号）；页面任何位置都没有写色板名称、色板总数、色号含义。
- 严重度：老手不敢确认这些色号能不能买到；新手无所谓。

---

## 一句话

**如果只改一件事，改这个：让「导出 PNG」导出的图能照着摆 —— 每格写上完整色号（A07 不能只剩 07），旁边加行列号和一页用量清单；或者干脆把这个按钮改名叫「导出预览图」，把「导出分板拼装图」提到主按钮的位置。**
