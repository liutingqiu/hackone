> 方式：真实浏览器（Chrome 156，headful，桌面 1280×992 CSS 像素；另测 390×844 手机视口），每一步都真实点击、真实上传、真实下载、真实打印预览。

**一个必须先说的前提**：本次测试期间线上站被重新部署过。11:42 首次打开时页面**没有**「小白 / 专业」切换，右侧默认露出「杂色合并阈值 / 显示色号 / 板尺寸」，同一张照片出 14 色；11:50 左右刷新后出现「小白 / 专业」，同一张照片出 36 色。两个版本的结论我都记了，下文标了「旧版 / 新版」。这不影响主要卡点（两个版本都复现），但会影响截图对不上。

## 0. 一句话结论

**「图能出，但拿不走。」** 首页那颗最显眼的「导出 PNG」，导出来的是一张没有色号、没有行列号、没有用量清单的彩色格子图 —— 它好看，但不能照着摆。真正能照着摆的东西（每格带色号、每板一页、带相邻板提示的 A4 分板图）藏在第二个按钮「导出分板拼装图」背后，而且点下去会突然弹出一个浏览器打印对话框。新手在第一步就会拿到错的那个文件，然后放弃。

## 1. A 人设：完全没玩过拼豆的大学生

设定：第一次听说「拼豆图纸」，手机里有一张风景照，想照着拼一个。

[A1] 我想先看看这是干什么的 → 页面顶部一行字「传图 → 出图 → 按色号摆」，中间大片空白写着「拖一张图进来 / 照片、截图、画画都行；越干净的原图，出来的图纸越好摆」，右上一个「上传图片」→ **顺利完成**，知道第一步是传图。

[A2] 我想先弄明白左边的滑杆是干什么的 → 左边是「每行格数 48」「格子大小 14px」「杂色合并阈值 2 颗」（旧版默认露出）。我不知道 48 是"48 颗豆宽"还是"48 像素"，也不知道"杂色合并阈值"是什么；拖了一下滑杆，画布还是空的，什么也没发生 → **卡住了（轻度）**，看不懂但可以先不管。

[A3] 我想传我那张风景照 → 点右上「上传图片」→ 选图 → 约 0.1 秒出图：图纸 48 × 48、总颗数 2304、颜色数 14（旧版），右侧列出 C04 棕肤 832、J03 灰棕 546…… → **顺利完成**，这一步体验很好。

[A4] 我想把图放大，看清每一颗是什么颜色 → 把「格子大小」从 14px 拖到 40px → 画布变成 1920px 宽，可视区只有 445px，**只能看到左上角大约 11 列**，而且格子里出现的色号被切掉了首字母：C04 显示成「04」，J04 也显示成「04」——两个不同的颜色在屏幕上长得一模一样 → **卡住了**。见 `docs/evidence/user-testing/a-03b-code-clipped.png`。

[A5] 我想知道某一颗到底是什么色号 → 按提示把鼠标移到格子上 → 右下角出现很小的灰字「光标: C04 棕肤」，但**被指的那个格子没有任何高亮**，我不知道这行字说的是不是我指的那一颗；提示文字在屏幕最右下角，第一眼根本没看见 → **勉强完成**。见 `a-04-hover-tooltip.png`。

[A6] 我想把图纸存下来 → 点右上「导出 PNG」→ **页面 5.2 秒毫无反应**（两次实测 5.21s / 5.22s），没有转圈、没有"正在生成"、没有完成提示；只有浏览器自己的下载栏多出一个 pattern.png → **卡住了（会以为没点上，连点两次）**。

[A7] 我想打开导出的图照着摆 → 打开 pattern.png：896×896，**只有色块、网格线、4 条红线、角落的板号 1/2/3/4**；没有色号、没有行列号、没有用量清单，图片四周还是透明的（在深色背景或照片冲印里会变成黑边）→ **卡住了**。这就是我拿到的"成品"，但它不能照着摆。见 `a-06-exported-png.png`。

[A8] 我想把它打印出来 → 浏览器打开这张 PNG → Ctrl+P → 一张 A4，图案缩在上半页，四周是黑的（透明区域被渲染成深色），没有任何标题、"共几颗""用什么色"的信息 → **卡住了**。见 `a-08-print-plain-png.png`。

[A9] 我好奇右边那个「导出分板拼装图」→ 点下去 → **新开一个标签页 + 浏览器打印对话框自己弹出来了**，5 页 A4：第 1 页总览（带用量摘要"共 2304 颗 · 14 色 · 4 块板"），第 2–5 页每块板一页，每格**写着完整色号**、上面有列号 1–29、左边有行号 1–29、页脚写「板 1/4 · 全图列 1-29 · 全图行 1-29」「相邻: 下 3 · 右 2」→ **顺利完成了，但我是懵的**：没人告诉我这个按钮才是"能打印的图纸"，也没人告诉我要在打印对话框里选"另存为 PDF"。见 `a-09b-split-board1.png`、`split-print-a4-5pages.pdf`。

[A10] 我手滑传了一个改了后缀的文本文件（.png 但其实不是图）→ **页面完全没有任何反应**，没有报错、没有红色提示，还是上一张图的画面 → **卡住了**，会以为网站坏了。见 `a-10-fake-file.png`。

[A11] 我传了一张全透明的图 → 页面安静地给出「48 × 48、2304 颗、1 色」的一张全白图，没有任何提示 → **卡住了（轻度）**，不知道是自己传错了还是网站坏了。

[A12] 我刷新了一下页面 → 图没了，所有设置回到 48/14，回到空白页 → **卡住了**。没有任何"未保存"的提醒。

[A13] 我用手机（390×844）打开 → 能传图、能出图；但顶部「上传图片」「导出 PNG」两个按钮被挤成两行字，画布 672px 宽塞进 390px 屏幕只能看到左边一半，空白页还在说「**拖**一张图进来」（手机上没法拖），底部提示「鼠标移到图纸上看色号」（手机上没有鼠标）→ **卡住了（轻度）**。见 `m-01-mobile-empty.png`、`m-02-mobile-result.png`。

### A 的总体感受
- 出图快、不用注册、手机上也能开，第一分钟的印象是"这玩意挺神"。
- 但**第一份成品是废的**：导出 PNG 不能照着摆。我发现"真正能用的东西"是碰巧点了第二个按钮才看到的。
- 术语里只有"色号"是我能猜懂的（因为旁边写了中文色名"棕肤"）；"分板"完全不懂——我不知道拼豆底板是 29×29，所以「2 × 2 = 4 块（29×29）」对我是天书。

## 2. B 人设：拼过几十张图的老玩家

设定：平时用 Excel 拉格子填色，或者手绘格子；手里有像素图，也有照片；在意色号、板数、能不能改单格。

[B1] 我想看看这工具是不是给我这种老手用的 → 新版顶部有「小白 / 专业」，默认停在小白；小白模式把「杂色合并阈值 / 显示色号 / 显示网格 / 板尺寸」都藏起来了，只剩「每行格数 / 格子大小」→ **顺利完成**，切到专业后参数才齐。旧版没有这个切换，一上来就是全参数。

[B2] 我传一张 32×32 的像素图（本来是 3 色）→ 默认「每行格数 48」，出图变成 **8 色 / 2304 颗**，出现了「F02 珊瑚红 4 颗」这种原图里根本没有的颜色，像素边缘被插值糊成了过渡色 → **卡住了**。我不知道要先改「每行格数」，页面也没提示"原图 32×32，建议用 32 格"。见 `b-02-pixel48.png`。

[B3] 我自己反应过来，把「每行格数」拖到 32 → 恢复 3 色 / 1024 颗，图案 1:1 正确 → **顺利完成（靠自己经验救回来的）**。见 `b-03-pixel32.png`。

[B4] 我想让它按我的板子来 → 「板尺寸」选 52×52 → 右侧变成「1 × 1 = 1 块（52×52）」；改回 29×29 → 「2 × 2 = 4 块」，画布上出现红线分板 → **顺利完成**。

[B5] 我勾上「显示色号」，想直接在屏幕上照着摆 → 14px 格子下**什么也没显示**；把格子放大到 40px，色号出现了，但每个格子只显示后一两位：A07 显示成「07」、A01 显示成「01」，首字母被切掉 → **卡住了**。MARD 里 A07 和 B07 是两种颜色，光看「07」没法摆。新版（MARD 291）更糟：G14 显示成「14」、H1 显示成「1」、C5 显示成「5」、M15 显示成「15」。见 `b-05-code-clipped.png`、`latest-code-clipped.png`。

[B6] 我想导出图，在手机/平板上照着摆 → 「导出 PNG」出来的图和 A 拿到的一样：**没有色号、没有行列号、没有清单**。对我这种人是直接不可用 —— 我宁愿回去用 Excel → **卡住了**。

[B7] 我改去点「导出分板拼装图」→ 打印对话框弹出，5 页 A4，每块板一页，每格**完整色号**（M13 / G13 / ZG5）、列号行号、页脚「相邻: 下 3 · 右 2」、总览页有「共 2304 颗 · 14 色 · 4 块板」和色号用量表 → **顺利完成，这是这个产品真正值钱的地方**。见 `split-print-a4-5pages.pdf`、`split-print-latest-36colors.pdf`。

[B8] 我想把用量清单抄进 Excel → 右侧清单是纯文字，不能选中、不能复制、没有「导出 CSV」，只能一个色号一个色号手抄 → **卡住了**。我用 Excel 就是为了这个表。

[B9] 我想改一个格子（原图有一处杂色）→ 页面上没有任何画笔、橡皮、撤销，只能重新传一张改好的图 → **卡住了**。这是 Excel 唯一比它强的地方，而它恰好是我最常用的动作。

[B10] 我刷新了一下 → 图没了，36 色的结果、分板设置全丢 → **卡住了**。见 `b-09-after-reload.png`。

[B11] 我看色板 → 同一张照片，旧版出 14 色、新版出 36 色，色号里出现了 ZG6、M9、H5 这种两位字母/一位数字的编号；我知道 MARD 是 291 色，但页面上没有任何地方写"当前用的是哪套色板、共几色" → **半卡**，不敢确认颜色能不能买到。

### B 的总体感受
- **分板打印是这个产品的杀手锏**，确实解决了"哪块板放哪、怎么对齐"——竞品（Jett-Wu 那类）只给一张图，这个给的是"拼装说明书"。
- 但**主按钮给错了东西**：导出 PNG 不能照着摆；能用的那个按钮名字叫"分板拼装图"，我还要猜它是不是我要的。
- 缺三样老手刚需：改单格、清单导出、色板说明。有这三样，我可以不再开 Excel。

## 3. 四个大众化问题，逐条回答

### 3.1 「拼豆图纸」「色号」「分板」这些词，新手看不看得懂
| 词 | 新手能否看懂 | 依据 |
| --- | --- | --- |
| 拼豆图纸 | **懂**。页面副标题「传图 → 出图 → 按色号摆」一句话说清了 | A1 |
| 色号 | **懂一半**。右侧列表有色号 + 中文色名（C04 棕肤），靠中文名能猜；但画布上的色号被切成「04」，反而看不懂 | A4、B5 |
| 分板 | **不懂**。「2 × 2 = 4 块（29×29）」默认用户知道底板是 29×29、知道"一块板"是什么。新手不知道 | A9、A2 |
| 每行格数 | **半懂**。不知道是"豆"还是"像素" | A2 |
| 杂色合并阈值 | **完全不懂**（旧版默认露出）。没有任何解释 | A2 |
| 小白 / 专业 | **懂**，但小白模式里仍然露出「分板 2×2=4块」「导出分板拼装图」，没有真正"一屏一动作" | B1 |

### 3.2 空的画布上，用户知不知道第一步该干什么
**知道"要传图"，不知道"传完之后会发生什么"。** 中央有大字「拖一张图进来」+ 一行说明，右上角有「上传图片」，指向明确（A1）。但：
- 没有示例图 / "试试这张"入口，新手不敢确定自己的照片行不行；
- 滑杆在空画布上就能拖，拖了没反应（A2）；
- 手机上还在让人"拖"（A13）。

### 3.3 导出按钮点下去之后，用户等不等得到反馈
- **导出 PNG：等不到。** 实测 5.21s / 5.22s 两次，期间无 spinner、无 toast、无按钮禁用态，页面像没反应（A6）。这是全站最伤的一个"我以为坏了"。
- **导出分板拼装图：反馈很强烈但方向错了。** 新标签页 + 浏览器打印对话框自动弹出（B7、A9）；如果弹窗被浏览器拦截，页面上没有任何提示，等于点了没反应。

### 3.4 出错时（传了张奇怪的图）有没有人话提示
**没有，一次都没有。** 四种错法全都静默：
| 我传了什么 | 页面反应 |
| --- | --- |
| 改了后缀的文本文件（fake.png） | 完全无反应，保持上一张图（A10） |
| 全透明 PNG | 安静地出「2304 颗、1 色」全白图（A11） |
| 纯白 500×500 | 同上，1 色（且没有"这张图没有内容"的提示） |
| 1×1 像素图 | 安静地拉伸成 48×48、1 色 |
| 1600×160 长条图 | 正常出 48×5，这是唯一"合理"的 |

## 4. 对比：不用这个工具，A 和 B 会怎么做

### A（新手）不用这个工具
1. 小红书搜"拼豆图纸"，找别人做好的图（免费，但只能拼别人选的图）；
2. 淘宝/闲鱼找"图纸代画"，**1–4 元/张**，发照片等 10 分钟到 1 天；
3. 手机装个像素画 App，自己一格一格涂（基本不可能，48×48=2304 格）。

**我们好在**：免费、不用注册、0.1 秒出图、手机能开、图不出浏览器（不用把照片发给陌生人）。
**我们差在**：给新手的第一份成品（导出 PNG）不能照着摆；如果他去代画，人家给的是带色号的图。等于我们把他领到门口，却没给他能拿进屋的东西。

### B（老玩家）不用这个工具
1. Excel 拉 48×48 网格、填色、手写色号 → 一张图 1–2 小时（含配色和数格子）；
2. 手绘格子纸，一张 A4 画 29×29，大图要画 4 张，靠自己对格子；
3. 用 Jett-Wu 这类生成器出图，再手抄色号到 Excel，仍然要人肉算分板。

**我们好在**：分板是自动的，而且直接给"每板一页 A4 + 行列号 + 相邻板提示 + 用量清单"，这部分能省掉他 1–2 小时里最枯燥的 80%；这是竞品都没有的。
**我们差在**：不能改单格、清单不能导 CSV、导出 PNG 不带色号 —— 正好是他用 Excel 的三个理由。

## 5. 值不值 1–4 元

- A：不会付。他要的是"一张能照着摆的图"，现在拿到的是"一张好看的图"，价值没闭环。
- B：**愿意付**，但付的是"分板 + 清单 + 每板一页"这套说明书，不是"生成图片"。如果导出 PNG 补上色号和行列号、清单能导 CSV，他会觉得 3–5 元/张合理（比他自己熬 1 小时便宜）。
- 共同前提：**先让"导出"给出能照着摆的东西**，否则付费点不存在。
