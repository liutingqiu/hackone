## 先报"修出新问题"

### ❗ 手机 390px 布局塌了（新引入，比修之前更糟）

- 复现：1280 桌面正常 → 切 390×844 → 刷新 → 上传任意照片。
- 看到：**页面横向溢出**（`body.scrollWidth = 603`，视口 390），标题「拼豆图纸」被挤成一列**竖排单字**，左边「每行格数 / 格子大小」标签被裁掉左半（显示成"行格数48""字大小3px"），右上「导出图纸（可打印）」被切出屏幕，画布缩成 **144×144**，并且「格子大小」被自适应压到 **3px**（滑杆最小值），整张图在手机上只有一枚邮票大。
- 对比：上一版手机端虽然画布被裁（672px 塞进 390px），但布局是正常堆叠的。
- 证据：`round2/r2-05-mobile-390-broken.png`。
- 影响：**手机是拼豆用户的主场景之一**，这一版等于把手机端做废了。桌面 1280 和平板 768 是好的（canvas 672/528，自适应格子 14px/11px，整图可见）。

### ❗ 主按钮「导出图纸（可打印）」不是下载，弹的是打印对话框；而且和「导出分板拼装图」输出完全一样

- 复现：上传图 → 点「导出图纸（可打印）」→ 新开一个 about:blank 标签（标题「拼豆图纸 · 分板拼装图」）+ 浏览器打印对话框自动弹出；**没有任何文件下载**。
- 输出内容：5 页 A4（1 页总览 + 4 页板），每格完整色号、行号列号、相邻板提示 —— 与「导出分板拼装图」**逐字节同构（同样 5 页、同样标题、同样内容）**。两个按钮现在是一个功能两个名字。
- 另外：弹窗被拦截时（`window.open` 返回 null）**页面毫无反应**，没有提示、没有降级。
- 证据：`round2/r2-08-main-print-5pages.pdf`。
- 建议口径（不涉实现）：主按钮要么直接给可下载的 PDF/PNG，要么在按钮旁写清"将打开打印窗口"；两个重复按钮合并。

### ❗ 「导出预览图（无标注）」仍然带红色分板线

- 复现：点「导出预览图（无标注）」→ 下载 `pattern-preview (4).png`（1344×1344，615ms）。
- 看到：色号确实没有、板号也没有，**但 4 条红色分板线还在**。文案说"无标注"，图里还有标注。
- 证据：`round2/r2-07-preview-still-redlines.png`。
- 影响：做分享图/打印垫图的人会拿到带红线的图，与字面承诺不符。

### ❗ 色号的中文色名消失了（新引入）

- 复现：任意图 → 右侧用量列表。
- 看到：上一版是 `C04 棕肤 832`（色号 + 中文名 + 数量），这一版是 `G13 413`（色号 + 数量），**中文名是空标签**（`<span class="name"></span>`）。
- 影响：新手唯一的"猜懂色号"的抓手没了；G13 / ZG6 / M9 对没玩过的人是纯噪声。第一轮报告里"色号懂一半靠中文名"的结论失效。

## 新问题（本轮新增）

1. **手机 390 布局塌陷**（详见上，P0）。
2. **主按钮与分板按钮功能重复**，且主按钮不产出可下载文件（P1）。
3. **预览图"无标注"仍带红色分板线**（P1）。
4. **色名消失**（P2，但直接影响新手理解）。
5. **小白模式无色号开关**：默认格子里不显示色号，用户必须切到"专业"才会看到这个选项；而"专业"这个词对新手的暗示是"这是给高手的"。既然色号修好了，建议默认就显示（或小白模式也保留一个"显示色号"）。
6. **toast 没有无障碍语义**：错误提示是普通 div，没有 `role=alert`/`aria-live`，读屏用户收不到；toast 出现在画布顶端居中，深色小字，离上传按钮（右上）有半个屏距离，视线容易错过。

## 本轮临时环境异常（供参考，非产品问题）
- 点「导出图纸（可打印）」后，浏览器打印预览会挂起该标签页，自动化工具无法再连接；已通过关闭打印标签恢复。真实用户看到的就是系统打印对话框，属预期，但自动化复测需要先 stub `window.print`。
