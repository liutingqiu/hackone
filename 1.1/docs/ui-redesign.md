# UI 重构规格（去 AI 味）

> 依据：docs/research/2026-11-07-douyin-ui-deai.md（五条视频的共识）
> 原则：规则管噪音，风格管识别度。我们只做前者——画布上的豆色才是主角。

---

## 一、核心判断

**这个界面的主角是画布里的几百种豆色，不是界面本身。**
所以 chrome（顶栏、面板、按钮）必须退到背景里：中性色、无渐变、无发光、装饰配额为零。
唯一允许的彩色是**进度**——它是用户唯一需要主动追寻的状态。

## 二、设计令牌（只用这几档）

    --space-1: 4px;  --space-2: 8px;  --space-3: 12px;
    --space-4: 16px; --space-5: 24px; --space-6: 32px;

    --radius-sm: 6px;  --radius-md: 10px;  --radius-lg: 16px;
    --radius-pill: 999px;

    --dur-fast: 120ms; --dur-base: 200ms; --dur-slow: 300ms;
    --ease-out: cubic-bezier(0.16, 1, 0.3, 1);
    --ease-in:  cubic-bezier(0.7, 0, 0.84, 0);
    --ease-io:  cubic-bezier(0.65, 0, 0.35, 1);

组内用 space-1/2，组间用 space-5/6。写死的 px 一律改掉。

## 三、颜色

中性色打底，只保留一个强调色：

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 背景 | #FAFAF9 | #0E0F11 |
| 面板 | #FFFFFF | #16181B |
| 文字 | #111214 | #EDEEF0 |
| 次要文字 | #6B6F76 | #9CA1A8 |
| 描边 | #E6E7E9 | #24262B |
| 强调（唯一） | #1F6FEB | #4C8DFF |

主按钮不用强调色，用墨色实心（浅色主题深底白字，深色主题白底黑字）。
强调色只出现在三处：选中态、焦点环、进度填充。

删掉：所有渐变、发光阴影、彩色阴影、emoji 图标。

## 四、排版

- 所有标签左对齐，同一列用 grid 而非逐个 margin
- 顶栏高 56px，左右内边距 space-5
- 左栏 248px，右栏 272px，中间自适应
- 组间 space-6（32），组内 space-2（8）
- 破坏性操作（重新开始）单独成组，描边按钮，不用实心

## 五、组件规范

### 按钮
| 类型 | 规格 |
| --- | --- |
| 主按钮 | 高 44，圆角 radius-md，墨色实心 |
| 次按钮 | 高 44，1px 描边，透明底 |
| 文本按钮 | 高 36，无边框，hover 变色 |
| disabled | 透明度 .45 |

按压：scale(.985)，dur-fast，松手用 ease-out 回弹。

### 分段控件（查看/标记、小白/专业）
容器 radius-lg，底色比面板深一档，内边距 2px；选中项面板色 + 1px 描边 + 轻阴影，不用强调色填充；切换用 dur-base + ease-io。

### 滑杆
轨道 4px，圆钮 18px，强调色只用于已填充部分；两侧 -/+ 按钮 44×44 描边。

### 列表（用量清单）
行高 36，左对齐四列（色块 16 / 色号 44 / 名称 1fr / 数量右）；分隔用 1px 描边色；hover 只改背景。

### 画布区
点阵背景保留（点距 16px，点色 = 描边色）；画布阴影只留一层 0 1px 2px rgba(0,0,0,.05)；圆角 radius-sm。

## 六、动效

| 场景 | 曲线 | 时长 |
| --- | --- | --- |
| 面板/抽屉出现 | ease-out | dur-base |
| 面板消失 | ease-in | dur-fast |
| 模式切换、分段滑块 | ease-io | dur-base |
| 按钮按压回弹 | ease-out | dur-fast |
| toast | 进 ease-out / 出 ease-in | 200 / 120 |

硬约束：
- canvas 重绘不加动画
- 尊重 prefers-reduced-motion: reduce，全部时长归零
- 不做弹跳、不超过 300ms、不做导致画布重排的动画

## 七、落刀顺序（改动从小到大，随时可停）

1. 令牌替换（纯 CSS 变量，30 分钟）
2. 去装饰（20 分钟）：删渐变、发光、彩色阴影、emoji
3. 左对齐与分组（30 分钟）
4. 组件改版（40 分钟）：按钮三态、分段、滑杆、列表
5. 动效（30 分钟）

每完成一步推一次。

## 八、验收

- [ ] 除强调色外无彩色（豆色除外）
- [ ] 间距全部来自六档
- [ ] 圆角只有 6/10/16
- [ ] 同列元素左边缘严格对齐
- [ ] 390/768/1024/1280 四宽度无溢出
- [ ] prefers-reduced-motion 下无过渡
- [ ] 主流程点击路径与改版前一致
