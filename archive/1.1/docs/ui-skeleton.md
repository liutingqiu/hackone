# UI 骨架（V1 定稿）

> 2026-11-07 · 主控定，开发部照此实现

## 布局：三栏 + 顶栏

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：深度思烤 · [小白|专业]   [上传] [导出]              │
├────────────┬────────────────────────────┬────────────────┤
│ 左栏       │ 画布                       │ 右栏           │
│ 控制区     │ （Canvas，居中，可滚动）    │ 用量 + 分板     │
└────────────┴────────────────────────────┴────────────────┘
```

## 模式切换

- 位置：顶栏中部，分段控件 `小白 | 专业`
- 切换只改**左栏可见项**与**右栏默认展开项**，不重建画布、不丢状态
- 默认进入小白模式

| 左栏内容 | 小白 | 专业 |
| --- | --- | --- |
| 上传 / 拖拽区 | ✅ | ✅ |
| 每行格数 | ✅ | ✅ |
| 格子大小 | ✅ | ✅ |
| 算法 / 取样 / 抖动 / 去背景 | ❌ | ✅ |
| 色板切换 / 跨品牌 | ❌ | ✅ |
| 编辑工具（画笔/填充/吸管） | 仅画笔+橡皮 | 全套 |
| 分板板尺寸 | ❌（固定 29） | ✅ |

## 分板面板（右栏，小白也显示）

```
分板
  6 × 4 = 24 块（29×29）
  [x] 画布显示板号
  [导出分板拼装图]
```

- 画布叠加：红色分隔线 + 每块左上角红色圆角标签（编号），编号先行后列
- 导出：多页可打印 HTML（overview 页 + 每板一页），四角裁切标记，边缘标**全局行列号**，页脚标相邻板编号

## 点格交互

- 单击格子 → 右栏顶部显示「A1 · #F9F0CD · 12 颗」
- 专业模式下再点一次进入改色（打开色卡）
- 小白模式不提供改色入口，避免误触

## 视觉约束

- 圆角 10–14px，跟随系统深浅色
- 画布背景用点阵，与图纸区分
- 数字一律等宽字体（Consolas / ui-monospace）
