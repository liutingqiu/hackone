# 产品白皮书（草案 V0.1）

> 2026-11-07 · 深度思烤队
> 用途：路演与技术评审的统一事实来源；V0.1 只覆盖 V1 范围，V2/V3 是路线图

---

## 1. 一句话

**把一张图变成能照着摆的拼豆图纸，并且告诉你需要几块板、每块板放哪、还缺多少颗豆。**

---

## 2. 问题

拼豆（fuse beads）正在从亚文化变成大众手工：

| 事实 | 数据 |
| --- | --- |
| 2025 年淘宝拼豆销售额 | **2.91 亿元，同比 +9018%**，淘宝年度十大商品第 2 名 |
| 小红书话题浏览 | **近 80 亿次**，年度十大出圈兴趣 |
| 抖音 Z 世代订单 | **+9018%** |
| 2026 预测规模 | 逼近 **10 亿元** |
| 头部品牌 Mard | 月销百万级，至今**每日限购** |

**但工具没跟上。** 玩家的真实卡点不在「生成一张图」，而在图生成之后：

1. 大图要拼成 9–16 块 29×29 底板，**哪块放哪、怎么对齐，全靠人肉数格子**
2. 摆到一半才发现**某个色不够**，小包拆了不能退
3. 想改一个格子，得重新生成整张图（现有多数工具会把手改清空）

---

## 3. 方案

### 3.1 双模式

同一套引擎，两种用法：

| | 小白模式（默认） | 专业模式 |
| --- | --- | --- |
| 面向 | 第一次玩、只想快点出图 | 手工圈老玩家、做定制单 |
| 色板 | 只用 MARD 291 | 9 套色板全开 |
| 参数 | 全默认，一屏一动作 | 算法/取样/限色/抖动全可调 |
| 编辑 | 画笔、橡皮、撤销 | 全套工具 + 快捷键 |
| 导出 | 图纸 PNG + 用量清单 | PNG / CSV / 分板 PDF |
| 跨品牌映射 | 无 | 有 |

切换不换数据结构，图纸可无损互转。

### 3.2 差异化：分板

竞品（含开源实现）都停在「出一张图」，最多在图上画 29 格的红线。**我们做到「怎么拼」**：

- 自动切板，每块板独立编号（1、2、3…，按拼装顺序）
- 每块板单独一页，四角裁切标记
- 板边缘标的是**全局行列号**，相邻两块共用同一坐标，靠坐标对齐
- 页脚标注相邻板编号（上/下/左/右）与该板起始拼装位置

### 3.3 库存缺口

从「采购清单」升级为「缺口清单」：输入手上已有的豆子数量，输出还差哪些色号、各多少颗。

**结论**：出图已经是红海；分板是空白。我们的叙事是「我们不重新发明生成，我们做生成之后那一步」。

## 5. 技术架构

- **栈**：Vite + React + TypeScript + Canvas 2D，无重 UI 框架
- **性能预算**：首屏 JS < 150 KB(gzip)；首屏可交互 < 1.5 s；400×400 重绘 < 16 ms；200×200 量化 < 300 ms 且不阻塞主线程
- **手段**：量化与最近色匹配放 Web Worker；画布视口裁剪分块重绘；色板按需加载（小白模式只打包 MARD 291）
- **部署**：Cloudflare Pages 静态站，子域 `hack.liutingqiu.xyz`，纯前端计算，图片不出浏览器

## 6. 数据合规

色号数据只采用 **MIT 授权**来源（HansBug/pindou-color-data 为主，Jett-Wu 交叉校验），HAMA 官方 PDF 用于人工核验。不使用 AGPL/GPL/无授权数据，避免商业化后的协议约束。

详见 [palette-sources.md](./palette-sources.md)。

## 7. 路线图

### V1（本次黑客松）
出图、色号、编辑、用量统计、**分板拼装图导出**、双模式切换、静态站上线。

### V2（如要长期运营）
- **账号与云端保存**：图纸存在云端，跨设备续编
- **图纸分享**：链接分享、社区图纸库
- **团队协作**：多人同编一张图
- 需要服务端能力，**腾讯云服务器在此阶段启用**（V1 不用）

### V3（商业化）
- 材料导流：按色号清单直接跳转购买
- 色板包：品牌联名色卡、定制色板
- B 端：手作店/教培机构的批量图纸与教学包

---

## 8. 商业假设（未验证，路演需谨慎表述）

- 工具本身难收费：小红书/闲鱼上图纸代画 **1–4 元/张**，免费开源工具众多
- 值钱的环节在「材料 + 社区 + 内容」，工具是入口
- 因此 V1 不做付费墙，先做使用量与留存

---

## 9. 风险

| 风险 | 应对 |
| --- | --- |
| 竞品快速补上分板 | 分板 + 库存的组合体验做深，形成工作流而非单点功能 |
| 色卡数据版权 | 只用 MIT 来源 + 官方 PDF 校验，公开署名 |
| 演示环境故障 | 静态站 + 本地离线版双兜底，录屏备份 |
| 两人两天做不完 | 严格按 P0/P1 冻结线，20:00 后只修 bug |
