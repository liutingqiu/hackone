# 拼豆图纸工具

把低像素图片（我的世界 16×16 贴图、像素画、照片）转成可打印的拼豆图纸；也可以新建空白画布从零画。
每个格子标出色号，点格子可查该像素的品牌色号与跨品牌对照，可导出带网格、坐标、用量清单的 PNG。

**直接用**：双击 `拼豆图纸工具.html`（Chrome / Edge 均可）。单文件、离线可用、不上传任何图片。

## 改了什么（相比旧版）

旧版图纸只是"原图的一次派生结果"：每次改尺寸、换品牌、换算法都会重新采样原图，
**手改的格子会被清空**。现在页面里维护一份真正的文档（`base` 色号网格）：

- **改尺寸、×2/×4/×8、换品牌、限色、配色整理，全部基于你当前看到的画面**，手改一路保留；
- 原图只在"导入"和「按原图重新识别」时使用；
- 新增空白图纸、绘图工具、色卡选色、相近色替换、撤销/重做。

## 怎么用

### 1. 导入图片，或新建空白

点左侧虚线框选文件、拖进来、或 `Ctrl+V` 粘贴。
导入后默认网格是原图的整数倍（长边约 32~80 格）；超过 400 格的大图会等比缩到 400 以内。

想从零画：在「画布」里填宽×高，点**新建空白**。空白图纸的所有格子是"空（不拼）"，
可以直接用油漆桶铺背景、用铅笔/形状画。

### 2. 画布尺寸 vs 成品尺寸（两个不同的东西）

| | 控件 | 行为 |
|---|---|---|
| **画布** | 宽×高 + 对齐（9 宫格）+「扩展 / 裁切画布」 | **1:1 增删格子，不缩放内容**。现有内容按「对齐」落在新画布里（左上/居中/右下等 9 个位置），新格子留空。缩小时被裁掉的格子会在提示里报数量，可撤销。 |
| **成品尺寸** | 边长 / 精确宽×高 / `×2 ×4 ×8` | **把当前画面整体缩放**到目标格数。放大一律最近邻（像素风不糊、颜色零误差）；缩小可选「最近邻 / 面积平均」。`×2 ×4 ×8` 是**相对当前画布连乘**，16→32→64 这样点。 |

面板实时显示格位数、成品厘米尺寸（按品牌豆径：国产 2.6mm / Hama·Perler 5mm / DMC 不折算）、
需要几块 29×29 底板。厘米数不含熨烫收缩，实物会略小。

> 要注意的是豆子数量按**面积**增长：16×16 点 ×4 就是 64×64＝4096 颗。

### 3. 色板与配色

- **品牌**：9 套色板。换品牌会把手里的豆色**就近映射**到新色板，不会退回原图、也不会丢手改。
- **显示色号**：选「标准291」时可切换 MARD / COCO / 漫漫 / 盼盼 / 咪小窝 五套色号。
- **匹配算法**：CIEDE2000（默认）/ Lab 欧氏 / RGB 加权。
- **取样方式**：最近邻（像素图）/ 平滑缩放（照片）。
- **最多色数**：把用得最少的颜色合并到最接近的保留色；这是非破坏性的，往回调能还原。
- **抖动 / 去周边纯色背景**：同上，只在识别时生效。
- **按原图重新识别**：识别设置（算法/取样/抖动/去背景）改完后取一次用户确认 ——
  点这个按钮才会用当前网格尺寸重新采样原图，**会覆盖当前画面，可撤销**。
  平时改这些下拉框不会动你的图纸。

### 4. 配色整理（新算法）

「配色整理」用来把**已经识别好的图纸**重新改色，避免颜色过多过杂：

1. **相近色聚类**：按 CIEDE2000 阈值把在用豆色并查集聚类，每一簇保留用得最多的那颗，
   其余全部替换成它（不会把差得远的颜色硬并在一起）；
2. **孤立杂色清理**（可选）：4 连通分量小于等于 N 格的零星色块，并入周围出现最多的颜色；
3. 一键应用，提示 "N 色 → M 色，改写 K 格"，**可撤销**。

强度预设：关 / 轻 ΔE≤4 / 标准 ΔE≤8 / 强 ΔE≤15。默认不自动执行，避免导入时不可预期地改色。

### 5. 工具

| 工具 | 说明 |
|---|---|
| 查看 | 点格子看色号、坐标、用量、跨品牌对照 |
| 铅笔 | 点/拖涂色，笔刷 1–16 格可调，画布上有笔刷范围 |
| 橡皮 | 点/拖擦除（擦掉的不参与统计） |
| 吸色 | 点格子把颜色取为铅笔色；**只读，不改图纸，不产生撤销记录** |
| 直线 | 拖一条直线，松开落笔 |
| 矩形 | 拖矩形，可勾「实心」 |
| 圆形 | 拖圆/椭圆，可勾「实心」 |
| 油漆桶 | 填充与点击处相连的同色区域，4/8 连通可切 |

- 形状工具拖拽时是**半透明预览**，松开才落笔；`Esc` 取消。
- 油漆桶按**完全相同的色号**判定连通（色板化后颜色是离散的，加容差会误伤相邻近似色）。
  在空白图纸上点一下，等于一键铺满背景。
- 一次拖拽 / 一个形状 = **一步撤销**。

### 6. 铅笔色与色卡

点工具栏「铅笔色」那一行打开色卡浮层：当前品牌全部颜色的网格 + 色号/HEX 搜索 + HEX 输入框。
输入任意 HEX 会**自动吸附到最近的豆子色**并显示 ΔE（保证导出的用量表永远有真实色号，不会出现买不到的颜色）。

右侧用量列表：**单击**某个颜色会在画布上高亮它的所有格子；**双击**直接设为铅笔色。

### 7. 相近色推荐 / 一键替换

单击用量列表里的某个颜色，右栏会出现「相近色推荐」：ΔE 最近的 4 个在用颜色，
带颗数和色差。点一下就把该颜色**全图替换**成候选色（一条可撤销记录），用来快速消灭近似色。

### 8. 撤销 / 重做

- `Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做，也有按钮；
- 改色、画笔、油漆桶、形状、相近色替换、**改尺寸、新建、导入、配色整理**都能撤销；
- 拖拽会合并成一步；撤销历史按内存封顶（约 64MB），400×400 也不会把浏览器撑爆；
- 在输入框/下拉框里按 `Ctrl+Z` 不会抢走浏览器的撤销。

### 9. 左右翻转（⇄）

把整张图纸水平镜像，用于熨烫后从背面看、或做对称图案。这是**持续状态**：

- 手改过的格子会跟着镜像；
- 改尺寸/换品牌后仍保持镜像方向；
- 撤销记录里的坐标会一起镜像，所以翻转后按「撤销」改的是**你看到的那一格**；

### 10. 导出

- **图纸 PNG**：带行列坐标、每格色号、每 29 格一块底板红线、底部用量清单，可直接打印。
- **用量 CSV**：色号 / HEX / RGB / 颗数 / 占比 + 其余色号体系的列。

| 色板 | 色数 | 说明 |

| 标准 291 | 291 | MARD 体系，同时带 MARD / COCO / 漫漫 / 盼盼 / 咪小窝 五套色号 |
| Hama | 50 | 5mm |
| Perler | 70 | 5mm |
| Artkal S | 35 | 2.6mm 软豆 |
| 卡卡 | 284 | |
| 柿柿 | 219 | |
| 童趣 | 120 | |
| 优肯 174 | 174 | Artkal 旧编号 |
| DMC 508 | 508 | 十字绣色卡，配色参考用 |

**同款牌子提示**：`小舞`、`黄豆豆`、`DODO` 三家的色号**彼此逐号完全一致**（同一套色卡换名），
所以没有单独列三套。

### 数据来源

- [Zippland/perler-beads](https://github.com/Zippland/perler-beads) — `src/app/colorSystemMapping.json`（291 标准色 × 5 品牌色号）
- [LunarXuan/Pindo](https://github.com/LunarXuan/Pindo) — `lib/data/palettes/` 下 8 套色板（Hama / Perler / Artkal S + 五套中文色号），并用于交叉校验
- [abearxiong/get-colors-from-beans](https://git.xiongxiao.me/abearxiong/get-colors-from-beans) — `colorMap.json`（卡卡 / 柿柿 / 童趣 / 优肯 / DMC）
- [Jett-Wu/Perler_Beads_Generator](https://github.com/Jett-Wu/Perler_Beads_Generator) — 第三方校验

原始文件都抓在 `data/raw/`，`python fetch_data.py` 可重新下载（已存在的会跳过）。

### 校验结果

- 五套中文色号（MARD / COCO / 漫漫 / 盼盼 / 咪小窝）：Zippland 与 Pindo **0 处冲突**（291 色逐个比对）。
- Zippland 的 MARD 291 色 vs Jett-Wu 独立实现：全部 ΔE < 2，互相印证。
- 小舞 / 黄豆豆 / DODO 与 get-colors 的 `Mard-291`：**291/291 色号完全一致**。
- **两版 MARD 不是同一张色卡**：色号编号 291/291 对得上，但只有 **17/291** 个 HEX 完全相同。
  这说明它是同一品牌的不同批次色卡，所以没有合并（本工具采用 Zippland + Pindo 那一版）。
- 上述两版之间共 171 处 HEX 不同，中位 ΔE 1.54（肉眼不可分），
  但**有 8 处 ΔE ≥ 5**，最大 ΔE 30 —— 例如 `ZG4` 一边记 `#96869F`、另一边记 `#96B69F`，
  典型的 8→B 串字。

## 已知限制（重要）

1. **HEX 是屏幕近似值。** 受显示器、光线、批次影响，实物颜色与屏幕必然有差。下单前请核对店家实体色卡。
2. **原图颜色常常在豆子色板里没有对应。** 实测一张 MC 风格贴图的主体绿
   `#4A8A3E`，最近的 MARD 豆子是 `B08 #1C9C4F`，**ΔE 已达 7.5**，属于肉眼能看出的差距。
   这是色板粒度问题，不是匹配错误；抖动、限色、配色整理能缓解，但无法消除。
3. **"吉元素"没有公开色卡。** 已检索多个色卡数据源（共 30+ 套色卡）、
   GitHub 仓库搜索、Bing / 百度 / 1688 / 淘宝，均无命中。
   判定方法：看它的色号格式 —— `A1/B12/M15/ZG1` 形式基本就是 MARD 系（照 MARD 买）；
   `A01/A02` 是 COCO 系；纯数字 `1/2/65` 是盼盼或咪小窝系。
4. **自定义颜色只能落在色卡内。** HEX 输入会吸附到最近的豆子色 —— 这是故意的：
   保证用量表里每个颜色都有真实色号可下单。
5. **画布上限 400×400。** 另外画布总像素设了上限（约 2400 万 CSS 像素），
   格子太大时「格子 px」会被自动压低，所以 400×400 时最多约 12px/格（放大编辑受限）。
6. **换品牌、拖动「最多色数」不单独进撤销。** 它们属于"重新配色"，改完再按撤销会撤到上一次绘图。
7. **配色整理是可撤销的破坏性操作。** 它会把相近色真的替换掉（同时改写文档），
   不是只看不改；「孤立杂色」阈值调大会吃掉刻意画的 1~2 格细节（默认 0 = 关闭）。
8. **只到 291 色为止的色板**。若你手上只有 221 色套装，请把「最多色数」调低，
   或自行在 `palettes.json` 里筛掉 P/Q/R/T/Y/ZG 系列。

| `界面截图*.png` / `示例图纸.png` | 界面与导出效果截图 |

### 重新生成

```bash
python fetch_data.py         # 数据 -> data/raw/（已有的跳过）
python build_palettes.py     # 原始数据 -> palettes.json（会打印交叉校验报告）
python build_html.py         # 模板 + 色板 -> 拼豆图纸工具.html
node verify.js && node verify_algo.js && node verify_integration.js
```

截图（需要 Edge）：

```bash
python make_screenshot_page.py export      # 生成 ._shot_export.html
msedge --headless=new --window-size=1700,1960 --screenshot=示例图纸.png "file:///.../._shot_export.html"
```

需要 Python 3 与 Node，无需任何第三方 Python 包（色彩数学是自己实现的，不依赖 numpy/Pillow）。
