## 怎么用

双击 `拼豆图纸工具.html` 即可。建议 Chrome / Edge / Safari 近期版本。

图片只在本机浏览器里处理，不上传。画布存在浏览器 IndexedDB 里，换浏览器或清缓存会丢。

## 功能清单

- 导入图片 → 自动转成拼豆图纸；也可新建空白画布
- 多画布管理：列表带缩略图，可切换、改名、删除
- 尺寸：宽高独立步进（长按连续加减）、等比、×2/×4/×8
- 配色：9 个品牌色板（含 291 色标准），色号体系切换，最多色数、抖动、去背景
- 识别算法：CIEDE2000 / Lab / RGB；最近邻 / 平滑取样
- 编辑：铅笔、橡皮、吸色、直线、矩形、圆形、连选填色、左右翻转，可撤销重做
- 滚轮缩放（光标锚点 + 缓动）
- 浏览 / 标记两种模式：按住拖动连续标记完成
- 右栏：像素检查器（跨品牌色号对照）、相近色替换、拼装进度、用量统计
- 导出：A4 拼装图（总览 + 每板一页）、PNG、用量 CSV、一键复制采购清单

## 如果打不开
