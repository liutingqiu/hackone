## 怎么用

双击 `拼豆图纸工具.html` 就能打开，不需要联网、不需要装任何东西、不需要起服务器。
建议用 Chrome / Edge / Safari 的近期版本。

图片只在本机浏览器里处理，不上传；草稿自动存在浏览器本地（localStorage），换浏览器或清缓存会丢。

## 里面有什么

- 上传图片 → 自动转成拼豆图纸，点阵大小、色板（含 291 色 / 常见品牌）、颜色合并可调
- 逐格编辑：能改单格颜色，能吸色、能批量替换
- 分板编号：按 A4 纸自动切板，每块带编号和行列坐标
- A4 多页拼装图导出：直接打印或存 PDF
- 浏览 / 标记两种模式：边拼边点掉，进度条按板统计
- 采购清单：每种颜色要几颗、对应色号，可复制、可跳淘宝搜
- 手机端单列布局

## 如果打不开

文件被系统当成文本了：右键 → 打开方式 → 选浏览器。或者把文件拖进浏览器窗口。
