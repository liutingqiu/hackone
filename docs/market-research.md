> 结论先放这：**这不是空白市场，是已经打起来的价格战。** 讲"市面上没有"会被评委一搜就拆穿。
> 但市场在爆发期，且有一个真空白：**大图跨板拼装**。

## 三、价格带（说明"谁付费"）

- **图纸代画/定制**：小红书闲鱼上普遍 **1–4 元/张**，带色号标注，「多买优惠」——说明**有真实交易，但客单价极低**
- **App**：Handpix / 素绘格 走 App Store 订阅或买断
- **线下体验**：拼豆套餐是手作店营收支柱（60%+）
- **材料**：Mard 等品牌靠豆子本身赚钱，月销百万、每日限购

推论：**工具本身很难收费**（1–4 元的代画在压价，免费开源工具一堆）。
值钱的是「材料 + 社区 + 内容」，工具只是入口。路演时别承诺"卖软件"。

## 四、真空白在哪

竞品全部停在「**生成一张图纸**」。真正让新手卡住的下一环没人做：

1. **大图跨板拼装** —— 拼豆板只有 29×29，一张 100×100 的图要分 9–16 块板。哪块先拼、板与板怎么对齐、拼完怎么拼起来，现在靠人肉数格子。**没有竞品在公开功能里提到分板/拼接编号。**
2. **手上已有豆的库存** —— 竞品给"采购清单"，但没人做"我已有 X 颗，还差 Y 颗"（导入已有库存 → 自动算缺口 → 生成补货单）。
3. **摆的过程引导** —— 分步骤高亮、按颜色一批一批摆、摆错了能拍照核对。这是「有回应」方向，正好能接硬件。
4. **社区/交易** —— 1–4 元的图纸交易已经在闲鱼/小红书自发形成，但没有垂直平台。

## 五、对参赛的三个影响

### 1. 话术必须改
不能说「市面上没有这样的工具」。改成：
> 「生成图纸这一步，开源社区已经做得不错了；**但生成完之后，怎么把它真正摆出来，没人管**。我们做的是后半段。」

这样反而更高级：承认前人工作 + 定位清晰，评委（尤其懂行的）会加分。

### 2. 开源合规（这条最重要）
赛制写明：**「使用开源项目或模板的作品，只评比赛两天内新增的部分」**。

- 汉堡包那版是这两天从零写的，没问题
- 但**千万别今天下午去 clone Zippland 或 liangdabiao 的代码**往里塞——一旦被看出是 fork，分数只算增量，等于白干
- 要借鉴就借鉴**思路**（池化取众数、BFS 合并同色、背景移除），自己重写
- Zippland 那个「开源共创声明」不是标准协议，商用/二次分发有风险，别碰

### 3. 差异化建议（48 小时内能落地的）
优先级从高到低：

- **A. 分板拼接（强烈建议）** —— 大图自动切板、每块板独立编号、板间对齐标记、拼装顺序。纯前端算法，**一天能做出肉眼可见的差异**，且竞品没有。演示时拿一张大图一切，评委立刻懂。
- **B. 库存缺口** —— 输入"我有多少豆"，输出"还差哪些色、各多少颗"。工作量小，但直击"摆到一半发现缺色"的痛点。
- **C. 拍照核对** —— 手机拍板子，自动标出摆错的格子。技术上有 OCR/图像对齐难度，**不建议 48 小时内碰**，可以放进"下一步"。

**我的建议：主推 A，附带 B。** 原方案里的编辑/调色板继续做，但那是"追上竞品"，不是"赢"。

## 六、路演修改版（5 分钟）

1. **30s 痛点**：举一张买来的图纸——"图太小、没色号、想改一点得重买"（保留）
2. **60s 承认现状**："生成图纸已经有人做了，开源免费。我们不一样的地方在后半段。"
3. **90s 演示**：传一张 100×100 的大图 → **自动切成 9 块板，每块带编号和对齐标记** → 库存缺口清单
4. **60s 用户验证**：今天下午拉人试用，他们卡在哪
5. **30s 价值**：工具免费引流，靠材料/社区变现；市场 2.91 亿、年增 90 倍

### 逐个记录

**1) Zippland / 七卡瓦 2.0（AGPL，ADR-003 已禁用于数据）**

- 路径：首页上传 → 编辑图片（裁剪/格子对齐/旋转）→ 完成 → 编辑器 → 调整 → 色彩 → 下载 → 拼豆。
- 「调整」页只有两个数字：**横轴切割数量**（默认 100，提示"建议 30~100"）、**颜色合并程度**。它们决定整张图多少格，不是决定切几块板。
- 「拼豆」模式里有一个**网格分割线**开关，但滑杆范围是 **5–20 格**（我读了 `input[type=range]` 的 min/max）——**根本调不到 29**。这是画辅助线，不是分板。
- 导出实测：100×100 图纸是一张 **3792×4944 px 的整图**，坐标从 1 连续编到 100，底部是"用料清单"（R08 1153 / B08 731 / H16 2875…）。**没有任何板块切分、板号、对齐标记**。源数据 CSV 是 100 行纯 `#RRGGBB`，也不带板信息。
- 「色彩」面板按颜色列出颗数（总计 10000 颗），可以点掉某色自动重映射——是**减色**，不是**库存**：全程没有"我已有 N 颗"的输入口。
- 结论：分板 ❌、板号 ❌、板级顺序 ❌、缺口 ❌。它解决的是"生成一张图"和"单颗怎么摆"。

**2) liangdabiao / LDB（Zippland 的分支改进版，加了 AI 与"专心拼豆"）**

- 路径：上传 → 确认裁剪 → 编辑（横轴切割数量 10–300 默认 60、颜色合并阈值、AI优化、一键去背景、处理模式、色号系统、去除杂色列表"总计 3600 颗"）→ 下载拼豆图纸 / 进入专心拼豆模式 / 手动编辑模式。
- 「专心拼豆（AlphaTest）」实测：顶部 `R01 0/300 预计还需30分钟`，右下 `下一个 → 3, 30`（下一颗的坐标），底部「颜色」面板按色号列进度（R01 0/300、H16 0/1616…），可按数量/进度排序。**这是逐颗导航，画面上仍是一整张图**，蓝线是可调辅助线，没有板。
- 导出实测：60×60 图纸 `bead-grid-60x60-keys-palette_MARD.png`（2008×2393 px，整图 + 色号 + 坐标 + 用料清单）。下载设置里勾"同时导出源数据"出 CSV，页面明写"导出hex颜色值的CSV文件，可用于重新导入"——**工程文件可回导**是它比 Zippland 多的一点。
- 库存 ❌：仍然只有"每种色用多少颗"。
- 小程序（perlerBeadsApplet）：**本轮未验证**——需要微信客户端，桌面浏览器环境登不进去。不作为结论依据。
- 结论：分板 ❌、板号 ❌、板级顺序 ❌、缺口 ❌。它把"生成后怎么摆"往前推了一步（逐颗坐标），但仍在**单板**世界里。

**3) Jett-Wu（唯一有"板"字样的产品，但不是我们要的那个）**

- 首页即工作台。顶部一行就是「拼豆板 [宽] × [高] [应用]」，预设 52×52 / 78×78 / 104×104 / 156×156。上传图片后右侧出 3D 预览 + 画笔/橡皮/填充/换色/吸管/图层/用量/调整，工具密度是四家里最高的。
- **有一个"块板"计数**：状态栏实时算 `87 * 87 - 7 色 - 2704 颗 - 4 块板`；`156 * 156 … 9 块板`；`52 * 52 … 1 块板`。按数值反推，它是把 **52×52 当一块板**在算块数（87/52 向上取整 = 2，2×2 = 4）。界面上没有任何"板尺寸"说明，这个 52 是我从三组数字反推的，标注为**推测**。
- 关键是：它**只告诉你需要几块板，不切图**。画布是一整张 87×87，导出对话框里只有：导出格式（PNG / PDF）、导出范围（图案尺寸 / 画布尺寸）、作品昵称、作者昵称、显示色号、辅助线——**没有"分板""板号""按板导出"任何一项**。
- 导出还有「导出用量」（Excel）和「导出编辑」（JSON，可再导入）。这两项是四家里工程化最好的。
- ❌ 未验证项：它的 PNG 我没抓下来（浏览器下载被拦），所以"导出的图纸里会不会画 52 格分隔线"没看到实物。结论只陈述界面：导出选项里没有板相关开关。截图 `docs/evidence/jett-4-generated.png`、`jett-5-canvas.png`。
- 结论：分板 ⚠️（只算块数、不切）、板号 ❌、顺序 ❌、缺口 ❌。

**4) mypindou 色卡站**

- 打开就是 MARD 291 色色卡，15 个系列（A–H/M + P/Q/R/T/Y/ZG），每个色块带 HEX + RGB；支持按色号/HEX/RGB 搜索、按系列分组，「点色块复制色号+HEX」，「复制当前清单」整段复制成备豆清单。
- 它**不做生成**（站内另有"拼豆生成器/参考图纸/拼豆教程/留言板"入口，本轮只按要求验色卡页）。所以分板/板号/顺序/库存四项都不适用且都没有；导出=剪贴板文本；免费。
- 对我们的用处：**这是做色卡对照与"备豆清单"文案的现成参照**（291 色、15 系列、HEX+RGB 全给），但按 ADR-003 不能直接抓它的数据当数据源。

### 一句话结论

**分板（把大图切成 29×29 底板 + 每块编号 + 拼装顺序）四个产品都没做。** 最接近的两个：Jett-Wu 会算"需要几块板"但按 52×52 计、只给总数、不切图；Zippland 系两家做了"单颗/单色的摆放引导"，但都在**一整张图**上，没有板的概念，更没有"先拼哪块、怎么对齐"。

### 给开发部的两个提醒（不改变 ADR，只是实测发现）

1. **板尺寸别写死 29**：竞品里 Jett-Wu 用 52×52 大板、我们文档一路写 29×29，实际市面上两种板都在卖。分板应做成可选板尺寸（29/52 至少都要能选），默认 29。
2. **"块板计数"已经有人做了（Jett-Wu）**，所以路演话术别说"连需要几块板都没人算"，要说"**算完块数之后怎么切、怎么编号、按什么顺序拼，没人做**"。这条比原来的说法更经得起评委当场点开对手网站核对。
