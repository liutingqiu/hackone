# 路演方案（网页版）

> 形式：一个网页，不是 PPT。现场直接打开、直接点。
> **硬约束：每组 5 分钟**（含视频）。按 5:00 排。

---

## 0. 为什么用网页

| 维度 | 网页 | PPT |
| --- | --- | --- |
| 现场可信度 | 讲完就能点，评委自己试 | 只能看 |
| 视频 / 二维码 / 在线地址 | 一个页面全装下 | 需要切窗口 |
| 改动成本 | 改一行部署一次 | 重排一页 |
| 风险 | 依赖浏览器；准备离线兜底 | 依赖投影仪分辨率 |

兜底：整页导出单文件 HTML + 视频本地 mp4，断网也能放。

## 1. 页面结构（7 屏 / 5 分钟）

| # | 屏 | 说什么 | 秒 | 累计 |
| --- | --- | --- | --- | --- |
| 1 | 封面 | 一句话 + 在线地址 | 15 | 0:15 |
| 2 | 问题 | 四个卡点：找图难、图太小、分板靠手算、进度靠记忆 | 40 | 0:55 |
| 3 | 洞察 | 真正的成本在「生成之后」 | 25 | 1:20 |
| 4 | **演示** | 90 秒录屏，全宽 | 90 | 2:50 |
| 5 | 差异化 | 市面缺放大/色号/分板/进度，我们一条龙 + 真实 A4 页 | 60 | 3:50 |
| 6 | 技术与数据 | 1751 色 / A4 210×297 / 38 字符短链 / 平板 | 45 | 4:35 |
| 7 | 结尾 | 团队 + 二维码 + 现在就试一张 | 25 | 5:00 |

比 10 屏版砍掉：单独的技术页、平板页、团队页——合并进第 6 屏和第 7 屏各一行。

### 交互

- 键盘 ← → 翻屏，空格下一页；滚轮吸附；
- 右下角进度点，可点击跳转；
- 视频：点击播放，播完显示「重播」；
- 每屏最多一句话 + 一个视觉，不放长段落。

## 2. 录屏怎么拍

### 2.1 装置

| 部件 | 选择 | 理由 |
| --- | --- | --- |
| 显示 | Xvfb :99，1920×1080 | 干净、可控、不录到桌面其他窗口 |
| 浏览器 | Chrome headful（kiosk 模式） | 有真实窗口与光标 |
| 操作 | xdotool（真实指针移动 + 点击） | 光标必须可见、轨迹自然 |
| 录制 | ffmpeg x11grab，30fps，H.264 | 系统级录制，含鼠标 |

不用 headless 的原因：headless 里没有系统光标，合成一个假光标不如真的。

### 2.2 分镜脚本（90 秒）

| 时间 | 动作 | 画面重点 | 字幕 |
| --- | --- | --- | --- |
| 0:00 | 首页空状态 | 「导入图片」 | 从一张图开始 |
| 0:04 | 点「导入图片」选图 | 文件对话框 | PNG / JPG 都行 |
| 0:10 | 识别完成 | 300×400 格、119 色 | 自动配色 |
| 0:15 | 限色拉到 40 | 色数下降 | 太多颜色拼不出来，先收一收 |
| 0:21 | 滚轮放大 + 拖动平移 | 格子与色号变大 | 放大到每一格 |
| 0:28 | 查看一格 → 铅笔改两笔 | 像素检查器联动 | 点格子查色号，直接改 |
| 0:34 | 直线 + 矩形 | 图形工具 | 直线 / 矩形 / 圆形 |
| 0:40 | 整理 ΔE≤8 | 颜色收敛 | 一键合并相近色 |
| 0:47 | 标记几格 + 标满一块板 | 「第 1 块板拼完了」 | 拼到哪、标到哪 |
| 0:56 | 导出 A4，翻两页 | 每板一页、板号、色单、比例尺 | 每块板一页 |
| 1:06 | 分享短链，复制 | 38 字符 | 微信直接发 |
| 1:13 | 新标签打开 | 图纸复现 | 换设备也能开 |
| 1:20 | 回画布全景 | 成品 | 生成之后，才是开始 |

动作本身约 72 秒，留停顿到 90 秒。

### 2.3 录制命令（草案）

    Xvfb :99 -screen 0 1920x1080x24 &
    DISPLAY=:99 google-chrome --kiosk --window-size=1920,1080 \
      --user-data-dir=/tmp/demo-profile https://hack.liutingqiu.xyz &
    DISPLAY=:99 ffmpeg -f x11grab -framerate 30 -video_size 1920x1080 \
      -i :99 -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p demo.mp4 &
    DISPLAY=:99 xdotool mousemove 960 620 click 1

### 2.4 后期

- 剪掉启动等待与识别等待（3 秒 → 1.5 秒，1.5 倍速）；
- 不加背景音乐，加轻字幕；
- 关键帧（A4 页、短链）在网页里用 CSS 局部放大，不改视频；
- 输出：1920×1080、30fps、H.264、8–15MB，另存一份 720p 备用。

## 4. 页面技术

- 单 HTML + CSS + JS，无框架，和工具同一套视觉（暖白、蓝主色、点阵）；
- 视频用 poster + 点击播放，不自动播放；
- 响应式：投影 16:9 为主，平板单列可翻；
- 部署：独立 Pages 项目（pitch.liutingqiu.xyz 或 /pitch），不碰主站；
- 体积目标：< 500KB + 视频。

## 5. 风险

| 风险 | 处理 |
| --- | --- |
| 现场网络差 | 视频与页面都准备本地离线版 |
| 投影偏色 | 主色只用蓝 + 中性灰，避免大面积饱和色 |
| 超时 | 视频可中途点击跳到「导出 A4」 |
| 评委追问技术 | 第 7 屏放数字，第 9 屏放仓库链接 |
