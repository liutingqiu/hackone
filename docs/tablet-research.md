# 平板屏幕比例调研（2026-11）

目标：给「拼豆图纸工具」做平板适配，手机端暂不做。

结论先行：**主流只有三种比例——4:3、16:10、3:2**，按出货量加权约 **45% / 30% / 12%**。
适配这三档，等于覆盖九成以上的平板。

## 三、安卓 / Windows 平板：常见 CSS 视口

| 视口（横屏） | 比例 | 典型机型 |
| --- | --- | --- |
| 1280 x 800 | 16:10 | 10–11" 安卓最常见档（2560x1600 @2x） |
| 1440 x 900 | 16:10 | Xiaomi Pad 6（2880x1800）、Galaxy Tab S9（2960x1848） |
| 1200 x 1920（竖） | 16:10 | 大屏安卓 |
| 1350 x 900 | 3:2 | Surface Pro（2880x1920 @2x） |
| 1800 x 1200 | 3:2 | Surface 大屏档 |
| 1920 x 1080 物理 | 16:9 | 影音向平板，占比下降 |

安卓 CSS 宽度受「屏幕密度 / 显示大小」影响，同一台机器可能报 800、900、1000 多，
所以适配要按**宽度区间**做，不要按机型做。

## 四、对我们这款工具的直接结论

当前布局固定三栏：300px + 画布 + 302px，两侧硬占 602px。

| 视口宽 | 留给画布 | 结论 |
| --- | --- | --- |
| 768（iPad 竖） | 166px | **不可用** |
| 820（iPad 10 竖） | 218px | **不可用** |
| 834（Pro 11 竖） | 232px | **不可用** |
| 1024（Pro 12.9 竖 / 老 iPad 横） | 422px | 勉强可用 |
| 1180（Air 横） | 578px | 可用 |
| 1366（Pro 12.9 横） | 764px | 舒服 |

竖屏平板必须换布局，光调间距没用。

### 建议的三档

| 宽度 | 布局 | 说明 |
| --- | --- | --- |
| **≥ 1024** | 三栏 | 侧栏压到 264 / 288，画布仍 ≥ 420 |
| **768–1023** | 画布优先 | 左栏变抽屉（顶部按钮呼出），右栏变底部抽屉；画布占满 |
| **< 768** | 不专门适配 | 手机端，保持现状 |

横屏 768 高（1024x768、1180x820）还要压纵向：banner + 工具条 + 画笔条现在约 140px，
平板收到 ~110px，左栏分组默认收起。

### 触控要改的点

1. **热区**：工具按钮现在 32px，触控下最小 40–44px；
2. **没有 hover**：data-tip 在触屏失效，关键按钮要有可见文字或长按提示；
3. **双指缩放/平移**：现在只有滚轮缩放 + 拖拽平移，平板需要 pinch；
4. **touch-action**：画布上要设 touch-action:none，防止双指触发页面缩放；
5. 长按步进器已有，保留。

### 测试矩阵（CSS px）

必测：768x1024、820x1180、834x1194、1024x1366、1280x800、1440x900
选测：744x1133（mini）、1366x1024（大 Pro 横）、1350x900（Surface）
