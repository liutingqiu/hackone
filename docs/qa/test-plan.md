### 1.3 不在 V1 验收范围

- V2 能力：账号、云端保存、链接分享、社区图纸库、多人协作、腾讯云服务端（WP §7）。
- P2：Minecraft mod 自动解压贴图、像素字体（WP/PLAN 的 P2）。
- 原生 App 打包与上架（Android/iOS）；若额外交付，另立 P1 清单，不占 V1 P0。
- 专业模式的跨品牌自动映射算法（F-32 只验「色板切换 + 授权署名」，不验映射精度）。
- 浏览器兼容矩阵：只承诺 Chrome/Edge 最新稳定版 + iPadOS Safari 最新版；Firefox 等不作为 P0。
