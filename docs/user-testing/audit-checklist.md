1. **build 标识**：`curl -s https://hack.liutingqiu.xyz/ | grep -o 'assets/index-[^"]*\.js'`（本轮 `index-xZbKlqHa.js`）。
2. **环境**：Chrome 156 headful；1280×800 / 768×1024 / 390×844（CDP 视口）；真实上传/下载/打印。
3. **A/B 两条关键路径**（每轮约 10 分钟）：
   - A：打开 → 传照片 → 看整图 → 导出预览图 → 点导出图纸（可打印）→ 关打印框。

4. **三态口径**：已修 / 未修 / 修出新问题；新引入的问题优先报。
